# Phase 5a — existing-attachment detection, local

- **Risk:** high. **Worker model:** opus (implementation worker, then a fix worker for the
  review findings). Run: `/autoclaude-opus`, driven, 2026-10-22.
- **Scope:** the local half of `PLAN.md` "### Phase 5" (its *Split* paragraph, recorded before
  the first worker): `Attach/AttachmentIndex`, attach becoming focus for a session already
  attached in this Mac's iTerm2, `detach(session:on:)` for every attachment of a session in this
  Mac's iTerm2, `e2e-local` extended, and a read-only probe `iterm2 attachments`. The remote SSH
  path is Phase 5b.

## What was built

- `Sources/MuxFinderCore/Attach/AttachmentIndex.swift`: lists tmux connections and asks each one,
  concurrently and through the D15 binding rule, the read-only identity `display-message -p`, with
  a 3 s timeout per connection. It maps a connection to a `SessionKey` by `#{host}` (byte-identical
  to `uname -n`), socket path, pid and start time, never titles, and counts unmapped connections by
  kind: unknown, ambiguous, stale, `nonUTF8`, plus filtered-out ones as excluded.
- Identity line (shared with the D15 coordinator check, one byte-level parser):
  `#{client_utf8}:#{n:host}:#{host}:#{pid}:#{start_time}:#{n:socket_path}:#{socket_path}:#{session_id}`.
  Length prefixes make the parse unambiguous; from a client not in UTF-8 mode a line is accepted
  only when host and socket path are printable ASCII with no `_` and no `:`, otherwise the
  connection is `nonUTF8` and never matches.
- Focus: an attach of a session the index finds attached ends `focused` (`requested → focused`)
  with no tab or window opened. Activation goes through
  `activateFirstTab(ofTmuxConnection:ownedBy:options:)` — `ListConnections`, owner check,
  `ListSessions`, `Activate` on one API connection. If the id was handed to another tab, focus
  moves to the session's next attachment; with none left the attach fails `attachmentChanged` and
  nothing is activated or opened.
- Index failure policy: iTerm2 not running → the attach proceeds; any other index failure ends it
  with `attachmentCheckFailed` before anything opens.
- `detach(session:on:)`: nothingAttached, detached, notSent, notClosed, cancelled, checkFailed;
  re-checks identity right before `detach-client`; only this Mac's host until 5b. Tabs this
  coordinator did not open count their 10 s minimum age from the end of the snapshot that revealed
  their connection; the identity-failure detach uses its launch's `CreateTab` time; the
  owned-connection `detach` still counts from the call (its caller saw the connection first).
- `e2e-local` is 10 steps: 5 focus existing (asserts this run's windows/tabs, every other window
  and tab, and the connection count unchanged, no launch tab, no argv digest), 6 detach by session.
  Its index gets a filter that asks only connections owned by the run's own launch tabs (chosen
  over a `ListConnections` pre-check, which leaves a gap where a new user connection would be
  asked). Probe `attach` and `iterm2 attachments` ask every connection: unattended use only when
  no user connection exists (`CLAUDE.md`, `docs/TESTING.md`).

## Decisions

- New **D16** in `PLAN.md` (matching, unmapped kinds, timeouts, focus semantics, index-failure
  policy, `detach(session:on:)`, real-run filter). D12 corrected (a non-UTF-8 client turns each
  non-ASCII *character* into one `_`), D15 and Phase 4 steps 7 and 9 edited for the new identity
  line, *Verified facts* extended.
- Verified on real tmux 3.8 (private `TMUX_TMPDIR` servers only): without `-u` under `LC_ALL=C`
  or no locale, `#{client_utf8}` is 0, tabs and `é` each become one `_`, combining and
  zero-width characters vanish, printable ASCII (`_`, `:`) is kept; with `-u` or a UTF-8 `LANG`
  it is 1 and bytes are exact; `#{n:}` counts bytes.
- Legacy coordinator tests run with the attachment check `.off`; new suites cover the default-on
  path.

## Review

Codex → `ship-with-fixes` (`docs/reviews/phase-5a.md`), 1 blocker and 2 should-fix, all fixed by
the fix worker with regressions that fail on the old behavior:

- **Blocker:** unknown tab age measured from call entry, so a tab created during discovery could
  be detached seconds after opening (modal hazard) → age counts from the end of the revealing
  snapshot; regression with 4 s discovery + 3 s listing → `detach-client` at 17 s.
- **Should-fix:** identity assumed tab separators survive in clients muxFinder did not launch →
  the `client_utf8` / length-prefixed line and the `nonUTF8` kind above.
- **Should-fix:** focus activated by the reusable short connection id alone → owner-bound
  activation above, with regressions for an id reused between index and activation.

## Consequences for later phases

- 5b must extend the index to remote hosts (host = the remote `uname -n` from discovery) and lift
  the this-Mac-only restriction in `detach(session:on:)`.
- A non-UTF-8 client whose host or socket path contains `_` or `:` stays `nonUTF8`; attaching
  that session can still open a duplicate (documented in D16).
- `focused` is published after activation, up to 5 s late when no tab appears yet.
- A connection that does not answer within 3 s does not block an attach; a duplicate is possible
  only if that connection was showing the same session.
