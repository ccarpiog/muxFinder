## Decisions (the worker's, within the calls)

- Folder search exists only in normal mode, so `--report-menu-bar-item` still reads no
  `preferences.json`.
- While a new text is being searched, earlier results whose names still match stay listed
  (so the list does not empty on every key) — after the review, only when the host and the
  scope also match.
- The scope save runs in a task the Settings model owns; `shutdown()` awaits it; the picker
  is disabled while a save runs, so saves never overlap.

## Review

Codex (`autoclaude-review.sh`, 20 min) → `ship-with-fixes`, 0 blockers, 2 should-fix —
`docs/reviews/phase-I-10b.md`:

1. Previous results kept across a scope change (Whole disk → Home folder left a `/Volumes/…`
   row selectable while the new query ran). Fixed: each previous answer keeps its scope; rows
   are reused only when host and scope match. Regressions in `FolderSearchSectionTests` and
   `FolderSearchModelTests` fail with the check removed.
2. The scope save ran in an untracked task, so quitting right after a change could lose it.
   Fixed: `chooseFolderSearchScope(_:)` starts a model-owned task, awaited by
   `setFolderSearchScope` and `shutdown()`. Regression in `SettingsFolderSearchTests` (gated
   store) fails with the wait removed.

## Open risks

- For the few milliseconds between a keystroke and the channel announcing the new search,
  only the old search's scope is known, so rows from the old scope can show for that moment
  (review-fix worker; dropped once the channel reports the new search).
- Full parallel `swift test` runs: in 2 of the worker's 7 runs one core process test went over
  its bound (`TerminalChildRunnerTests.cancellationInterruptsTheCheck`, untouched, and
  `FolderSearchTransportTests.answersAndEndsAtEndOfInput`'s 2 s close); both suites passed 15
  runs in a row alone; the orchestrator's final runs passed. Load-sensitive, like the
  private-server tests already noted.
- Owed to the user (checklist 24): a real search on Saturno, no privacy prompt on This Mac's
  first search, whether Desktop/Documents/Downloads folders appear on This Mac, the links, and
  VoiceOver.
