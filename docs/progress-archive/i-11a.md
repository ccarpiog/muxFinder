## Review

Codex (`autoclaude-review.sh`, 20 min) → `ship-with-fixes`, 1 blocker + 2 should-fix,
`docs/reviews/phase-I-11a.md`. A review-fix worker:

- **Blocker (the check does not bind the detach) — narrowed, not closable; recorded in D37.**
  No single guarded command exists within tmux 3.8 and iTerm2 3.7.7: the command `if-shell`
  inserts gets its own reply block marked flag 1 (iTerm2 would pair it with its next
  command); iTerm2 ignores a flag-0 block only when it ends with `%end` (a flag-0 `%error`
  aborts); iTerm2 tolerates no tmux error from an API command (a "tmux Reported a Problem"
  alert and the connection ended, read from iTerm2's public source, not triggered for real);
  inside `if-shell -F`, `#{L:}` sees only the sender's session. Narrowed: the listing and the
  check filter all clients server-wide (no `-t`, so they cannot fail), and the check binds
  name, pid, creation time and session id. Residual: within the one round trip between check
  and detach, a checked client that switches sessions is detached from its new session, and
  one that ends makes `detach-client` fail, which on iTerm2 3.7.7 also ends the kept
  attachment with that alert. Nothing is ever killed.
- **Should-fix (a tmux error counted as a detach) — fixed.** An iTerm2 `SendCommand` answer
  without `output` (or without a payload) is now `ITerm2Error.tmuxCommandFailed`, never an
  empty success (`ITerm2APIClient.commandOutput(of:)`); a detach so answered is not counted,
  earlier ones keep their count; the attach's identity check retires such a connection as it
  does an unreadable answer. Three new golden fixtures (the 44 existing byte-identical).
- **Should-fix (age protection misses later clients) — fixed.** Every client in the listing
  must be 10 s old by tmux's clock (`%s` against `#{client_created}`, +1 s for rounding)
  before anything is checked or detached; the wait is at most 10 s after the listing. A wall
  clock jump on the tmux host could shorten it (recorded in D37).

Each regression failed with its fix reverted (4, 3 and 8 issues) and passed restored.
