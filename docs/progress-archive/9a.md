## Decisions

- **D23 — Settings window**: one reusable AppKit window (`SettingsWindowController.shared`),
  not a SwiftUI `Settings` scene (an accessory app cannot reliably open and front it);
  `SettingsEnvironment` seams for persistence, discovery, profiles (never launches iTerm2),
  suggestions, login item, diagnostics, pasteboard and URL opening; explicit Save/Revert
  drafts with inline sentence-case validation; This Mac demotion on save; changed-file and
  unusable-file banners with "Reload" / "Replace…" (nothing editable until chosen);
  diagnostics name hosts by display name and id only; `--report-login-item-status`.
- `HostStore.save(_:expecting:)` (D19): every load returns the file's revision, and a save that
  expects a revision refuses when the file on disk changed (a missing file that appeared
  counts). The unchecked `save(_:)` stays for tests and tools.
- Removal while editing: preserve (editing stays enabled; the editor moves on only if it still
  shows the removed host).

## Review

Codex → `ship-with-fixes`, `docs/reviews/phase-9a.md` (brief `phase-9a.brief.md`):

1. **Blocker — stale save over a changed file.** Settings saved through the load state it had
   at opening, so a `hosts.json` replaced since (even with malformed JSON) was overwritten
   without the explicit Replace consent. Fixed with `save(_:expecting:)` and the changed-file
   banner; regression `changedFileIsNotReplaced` failed on the old code (file overwritten,
   backup made).
2. **Should-fix — probes outlived shutdown.** `SettingsModel.shutdown()` now refuses new work
   and cancels and awaits probes and the opening, called first by `AppModel.shutdown()`;
   `shutdownStopsSettingsProbes` failed on the old code (0 of 2 probes ended).
3. **Should-fix — close during opening.** The model owns and cancels the opening task (and its
   profile request); results are dropped by window generation;
   `closingWhileLoadingStopsTheOpening` and `closingCancelsTheProfileRequest` failed on the
   old code.
4. **Should-fix — removal reset a newer selection.** `editsMadeWhileARemovalSavesAreKept`
   failed on the old code.

## Open risks
