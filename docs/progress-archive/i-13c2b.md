## Decisions

- **`canUpdate` gates only Update** (the worker's, recorded in D39): `canUpdate` is false for
  a Download offer, so the calls read literally would never show "failed with Download";
  Download now shows whenever the offer is Download. Codex judged the deviation sound.
- Wording (the worker's, within the calls): "Can't update in place: <reason>", "Quitting to
  install loses <items>.", "Download checked" for the transient prepared state.
- The notice counts as visible for announcements only when the popover's main layout shows
  and a release is displayed (slightly stricter than "popover visible"; review-fix worker).
- I-13c1's "Update available: the notice" card kept in the gallery before the 13 new states.
